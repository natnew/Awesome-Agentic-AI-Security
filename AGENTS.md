# AGENTS.md

## Project Overview

The Awesome Agentic AI Security repository is a curated body of knowledge and reference architecture for securing autonomous, tool-using, and cyber-capable AI systems.

This repository organizes security primitives into five functional categories reflecting the **AI Defense Plane** (Discover, Protect, Govern):

- **[Docs](docs/)**: Theoretical and tactical security foundations.
- **[Patterns](patterns/)**: Hardened engineering specifications.
- **[Resources](resources/)**: Evidence-led indexes of tools and research.
- **[Rubrics](rubrics/)**: Readiness evaluation frameworks.
- **[Visuals](visuals/)**: Reference architectures and Mermaid diagrams.
