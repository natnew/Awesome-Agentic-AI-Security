# CLAUDE.md

## Coding Standards

### Project Structure
- `docs/` - Core documentation (Threat Models, Attack Surfaces)
- `patterns/` - Secure engineering patterns
- `resources/` - Curated indexes (Tools, Benchmarks, Papers)
- `visuals/` - Mermaid diagrams and architectures
- `rubrics/` - Evaluation frameworks
- `site/` - Astro/Starlight web source

### Markdown Guidelines
- Use descriptive headers and structured lists
- Follow frontmatter requirements for agents, instructions, and skills
- Maintain cross-links between documentation sections

### Security Focus
- All contributions should align with the AI Defense Plane (Discover, Protect, Govern)
- Ensure threat models and attack chains are grounded in research or evidence
